# Открытые научные проекты ИТМО

Открытый код помогает воспроизводить научные результаты, развивать идеи других
исследователей и создавать новые инструменты вместе. В этой подборке собраны
программные проекты, связанные с исследованиями и разработками Университета ИТМО:
библиотеки, инструменты, экспериментальный код и другие научные разработки.
Подборка охватывает разные направления и подразделения университета.

Это часть [open-source-ops](https://github.com/aimclub/open-source-ops) — коллекции
инструментов, инструкций и лучших практик для создания и сопровождения открытого
кода. Больше о сообществе — на [ITMO OpenSource](https://opensource.itmo.ru).

Если проект оказался полезен, поддержите его звездой на GitHub или расскажите
авторам, как используете их разработку.

## Проекты по годам

Список формируется автоматически по данным базы научного кода ИТМО. Каждый проект
указан один раз — в году самой ранней связанной с ним публикации. Это год статьи,
а не дата создания репозитория. Проекты, для которых год неизвестен, находятся
в разделе «Без года».

Название статьи ведёт к исходному коду, а ссылка «статья» — к публикации.
Если название статьи отсутствует, приводятся имя репозитория и его краткое
описание, когда оно есть.

## Предложить проект или исправление

Знаете научный программный проект ИТМО, которого нет в списке, или заметили
неточность? [Создайте issue](https://github.com/aimclub/open-source-ops/issues/new)
со ссылкой на репозиторий, кратким описанием и, при наличии, связанной статьёй.
Публикация не обязательна.
