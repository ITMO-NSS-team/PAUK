# `pdf` — стейдж

**Что здесь:** самый маленький стейдж пайплайна — что он делает и как
соотносится со стейджем `code_links`, где фактически идёт работа с PDF.

**Какие файлы задействует:** `pauk/pipeline/stages/pdf.py`.

Не скачивает ничего, только фиксирует дешёвый, отдельно резюмируемый
сигнал — есть ли у публикации `pdf_url` от OpenAlex:

```python
status = COMPLETED if publication.pdf_url else NOT_APPLICABLE
```

Само скачивание и разбор PDF (pymupdf, постраничный текст, поиск ссылок)
идёт в стейдже `code_links` — там же, где результат в первую очередь и
нужен, см. [code-links.md](code-links.md).
